Multi-Sensor Arduino Control Panel

Button-controlled temperature, distance, and ambient light monitoring system

About the Project

This project is designed to query different environmental metrics (temperature, distance, and light level) dynamically via push buttons and display the real-time data instantly on an LCD screen. The core processing unit of the system is an Arduino Uno microcontroller.

Using the control buttons, users can:

  • Read the current room temperature using the DHT11 sensor.
  • Measure object or obstacle distance in centimeters using the HC-SR04 ultrasonic sensor.
  • Analyze the ambient brightness / light level using the LDR sensor.

Components Used

Arduino Uno

Main control unit and processing core.

DHT22 Sensor

High-precision temperature & humidity measurement.

HC-SR04 Sensor

Ultrasonic distance detection.

LDR & LCD Screen

Light intensity reading and real-time display.
